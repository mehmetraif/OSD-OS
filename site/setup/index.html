OSD/OS SETUP SETTINGS FOR THE CARD

Choose OSD/OS's settings in your browser before the card goes into the Pi: they go onto the card as one file, and OSD/OS applies them as it starts.

What the card goes into comes first, a TV or an arcade cabinet; then the display output, Wi-Fi and the device's name, the system, and every setting of OSD/OS itself, with its look shown as it draws it. Three views show them: Basic, how it starts and its look; Logins, what it signs in with; Advanced, every setting. Download puts them in one file, osdos-setup.json; copy it to the card's boot partition (the drive called bootfs), and OSD/OS applies it all as it starts, then deletes the file. OSD/OS on a computer takes its own settings from it too (On a computer).

Nothing you type leaves this page: the file is made in your browser. Only what you change goes into it (marked •); the rest stays as the card has it. Import reads a file made here back, or OSD/OS's own config.json, to change it.

On the card

  1. Write the OSD/OS image to the card (Raspberry Pi Imager, Use custom).
  2. Take the card out and put it back in: the computer shows its boot partition as bootfs.
  3. Copy osdos-setup.json there. With a display output chosen, also copy osdos-display.txt over the one there, so that a CRT has its picture from the first start (the zip holds both).
  4. Put the card in the Pi and switch it on. OSD/OS takes the file off the card at once, sets its own settings before it starts, and the rest while its boot screen shows SETTINGS; it restarts once if the display output needs it. osdos-setup.log on bootfs says what was done, and why anything wasn't.
      ____________________
     /  bootfs           |
    /                    |
   |  osdos-setup.json   |
   |  osdos-display.txt  |
   |                     |
   |_|_|_|_|_|_|_|_|_|___|

The file can go on a card that has already started too: OSD/OS applies it at the next start. It holds the Wi-Fi and RetroAchievements passwords as you typed them, and pi's password only as a hash: keep it to yourself.

On a computer

OSD/OS on Windows, macOS, Linux or a BSD takes two parts of the same settings: its own, and the RetroAchievements account. The device's name, the display output, Wi-Fi and the system are set on a card alone.

  • Copy for a computer, then in OSD/OS, Settings → Paste OSD/OS Setup: they are set at once.
  • Or put osdos-setup.json in OSD/OS's data folder, or beside the app: OSD/OS applies it as it starts, says what it set, and deletes the file. The data folder is %APPDATA%\OSD-OS on Windows, ~/Library/Application Support/OSD-OS on macOS and ~/.local/share/OSD-OS on Linux and the BSDs. Beside the app is the osdos folder with osdos.exe, the folder osdos.app is in, or the AppImage's.
